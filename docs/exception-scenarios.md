# 异常场景说明

## 1. 库存相关异常

### 1.1 并发扣减导致超卖
- **场景:** 多个订单同时购买同一商品，库存仅够其中部分订单
- **处理方式:** 使用乐观锁（version字段），扣减时检查版本号匹配才生效
- **用户表现:** 后提交的订单会收到"库存不足"错误提示
- **最大重试:** 3次，全部失败返回"库存更新冲突，请重试"

### 1.2 库存调整为负数
- **场景:** 管理员手动出库数量超过当前库存
- **处理方式:** 校验 `当前库存 + 调整量 >= 0`，不允许负库存
- **错误信息:** "调整后库存不能为负数"

### 1.3 库存调整低于锁定量
- **场景:** 管理员减少库存，但减少后低于已锁定数量
- **处理方式:** 校验 `调整后库存 >= 锁定库存`
- **错误信息:** "调整后库存不能小于锁定数量"

### 1.4 商品不存在时的库存操作
- **场景:** 请求中的 productId 不存在
- **处理方式:** 返回 404 "库存记录不存在"

## 2. 订单相关异常

### 2.1 非法状态转换
- **场景:** 尝试将订单从不允许的状态转换到目标状态
- **处理方式:** 通过 ORDER_TRANSITIONS 映射表校验，不在允许列表中则拒绝
- **示例:**
  - `pending_payment → shipped` (不允许，必须先经过 paid → shipping)
  - `cancelled → paid` (不允许，已取消是终态)
  - `paid → cancelled` (不允许，已付款只能发货或退款)
- **错误信息:** "订单状态不允许从 X 变更为 Y"

### 2.2 下单时商品已下架
- **场景:** 提交订单时包含已下架商品
- **处理方式:** 检查每个商品的 status，已下架则拒绝
- **错误信息:** "商品 'XXX' 已下架"

### 2.3 下单时库存不足
- **场景:** 提交订单时商品可用库存不足
- **处理方式:** 逐个锁定库存，失败时事务回滚
- **错误信息:** "库存不足" 或 "可用库存不足"

### 2.4 优惠券使用异常
- **场景描述及处理:**
  - 优惠券不属于该用户 → "优惠券无效或已使用"
  - 优惠券已使用 → "优惠券无效或已使用"
  - 优惠券已过期 → "优惠券不在有效期内"
  - 优惠券未到使用时间 → "优惠券不在有效期内"
  - 订单金额未达门槛 → "订单金额未达到优惠券最低使用金额 ¥XX"
  - 优惠券已禁用 → "优惠券已失效"

### 2.5 取消订单后的回滚
- **处理:** 释放锁定库存 + 归还优惠券使用次数 + 将用户优惠券状态改回 unused

### 2.6 退款后的库存归还
- **处理:** 将扣减的库存加回 + 归还优惠券

## 3. 认证与权限异常

### 3.1 登录失败
- 用户名不存在 → "用户名或密码错误"（不暴露是用户名还是密码错误）
- 密码错误 → "用户名或密码错误"
- 账号被禁用 → "账号已被禁用"

### 3.2 Token 异常
- Token 过期 → 401，前端跳转登录页
- Token 无效/被篡改 → 401
- RefreshToken 过期 → "RefreshToken已过期，请重新登录"

### 3.3 权限不足
- 无所需权限 → 403 "权限不足"
- 未登录 → 403 "未登录"
- super_admin 角色绕过所有权限检查

## 4. 数据完整性异常

### 4.1 重复数据
- 管理员用户名重复 → "用户名已存在"
- 角色名/编码重复 → "角色名或编码已存在"
- 商品SKU重复 → 数据库唯一约束错误
- 优惠券码重复 → 数据库唯一约束错误

### 4.2 删除约束
- 删除有子分类的分类 → "该分类下存在子分类，不能删除"
- 删除有商品的分类 → "该分类下存在商品，不能删除"
- 删除已使用的优惠券 → "该优惠券已有使用记录，不能删除"
- 删除有订单的商品 → 自动改为下架（status=0），不物理删除

## 5. 导入导出异常

### 5.1 导入文件格式错误
- 非 xlsx 文件 → "Excel文件格式错误"
- 缺少必填列 → "第X行: 缺少必填字段"
- 数据格式错误 → "第X行: 错误信息"

### 5.2 导入部分失败
- 返回 `{ success: N, failed: M, errors: [...] }` 结构
- 成功的记录保留，失败的记录跳过并报告错误

## 6. 通用异常

### 6.1 参数验证失败
- 由 class-validator + ValidationPipe 自动处理
- 返回 400 + 具体字段错误信息

### 6.2 资源不存在
- 返回 404 + "XXX不存在" 信息

### 6.3 服务器内部错误
- 未捕获的异常由 HttpExceptionFilter 统一处理
- 返回 500 + "服务器内部错误"（不暴露详细错误信息到前端）
